# Visão geral.

- Disponibilize seu serviço de rede HTTP (ou HTTPS) usando um mecanismo de configuração com reconhecimento de protocolo, que compreende conceitos da web como URIs, nomes de host, caminhos e muito mais. O conceito Ingress permite mapear o tráfego para diferentes backends com base em regras definidas por meio da API do Kubernetes.

- Fonte/Documentação: https://kubernetes.io/docs/concepts/services-networking/ingress/
