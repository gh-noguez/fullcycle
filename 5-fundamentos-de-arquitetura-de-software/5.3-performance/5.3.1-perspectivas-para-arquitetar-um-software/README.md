# Perspectivas para Arquitetar um Software.
Ao arquitetar um software, existem três perspectivas fundamentais que ajudam a prever o sucesso de uma aplicação quando ela entra em produção.

1. Performance
    - Esta perspectiva foca em como o sistema se comporta sob carga. É preciso entender e utilizar as métricas corretas para garantir um bom desempenho. Um software de qualidade deve ser capaz de processar as requisições de forma eficiente, proporcionando uma boa experiência ao usuário.

2. Escalabilidade
    - A escalabilidade trata da capacidade do sistema de crescer e se adaptar ao aumento de usuários e acessos ao longo do tempo. Uma arquitetura escalável permite que o software mantenha seu bom comportamento mesmo quando a demanda aumenta significativamente.

3. Resiliência
    - A resiliência é a capacidade de um software de falhar e se recuperar rapidamente. É essencial partir do pressuposto de que todo software e sua infraestrutura podem falhar (falhas de datacenter, rede, bugs). Ter soluções e planos B é fundamental para garantir que o sistema continue funcionando ou se recupere rapidamente em caso de imprevistos.
