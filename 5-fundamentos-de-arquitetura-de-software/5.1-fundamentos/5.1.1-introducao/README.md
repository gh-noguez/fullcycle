# Introdução.

### Fundamentos de Arquitetura de Software
Este módulo introdutório, apresentado por Wesley, visa fornecer um quickstart no mundo da Arquitetura de Software.

### Importância da Arquitetura de Software
Compreender a Arquitetura de Software é fundamental para quem deseja trabalhar em grandes projetos. Ela impacta a carreira em diversos aspectos, incluindo:

- Aspectos técnicos: Melhora a abordagem e execução de projetos.

- Aspectos de cargos e nomenclaturas: Ajuda a entender as diferentes posições e responsabilidades no campo.

### Tipos de Arquitetos
Durante o módulo, serão abordados diferentes tipos de arquitetos:

- Arquiteto de Software

- Arquiteto de Solução

- Arquiteto Corporativo

- Arquiteto Tecnológico

Este apanhado de conceitos visa expandir o nível de consciência do aluno, revelando as diversas possibilidades de carreira.

### Estrutura do Módulo
O conteúdo será denso, mas de extrema importância. Todos os conceitos apresentados serão cruciais para "juntar as peças" na trajetória profissional.
