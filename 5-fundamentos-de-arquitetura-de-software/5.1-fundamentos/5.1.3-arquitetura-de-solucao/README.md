# Arquitetura de solução.

#### Arquitetura de Soluções e Arquitetura de Software
No vídeo anterior, abordamos arquitetura tecnológica e corporativa. Agora, focaremos em arquitetura de soluções e arquitetura de software.

#### Arquitetura de Soluções
O arquiteto de soluções é um papel muito comum.

#### Papel do Arquiteto de Soluções
- Atua na interseção entre a área de negócios e a área de software.

- É uma função técnica com uma visão clara do negócio.

- Transforma requisitos de negócio em soluções de software: Compreende necessidades complexas das empresas e as traduz em soluções implementáveis.

- Cria desenhos arquiteturais: É essencial que saiba desenhar para reproduzir como o software funcionará. Utiliza diagramas para documentar e expressar o pensamento.

    - Exemplos de diagramas: Diagrama C4, UML, BPMN.

#### Análise de Impactos e Contexto
- Analisa impactos comerciais em escolhas tecnológicas: Entende que existem diversas formas de desenvolver uma solução e escolhe a tecnologia com base no contexto do cliente.

    - Exemplo: Se a infraestrutura existente do cliente é toda AWS, não se deve sugerir a migração para Google Cloud apenas por preferência, a menos que haja um forte impacto financeiro justificável.

    - Exemplo: Se o banco de dados central é Oracle, não se deve mudar para SQL Server sem um motivo muito forte.

- Deve ter bom senso para fazer escolhas tecnológicas que façam sentido a curto, médio e longo prazo.

#### Envolvimento no Processo de Vendas
- É muito comum o arquiteto de soluções participar de reuniões com clientes no estágio de pré-venda e venda.

- Acompanha consultores ou "closers" que podem não ser especialistas em software, para apresentar detalhes mais técnicos e demonstrar como uma solução pode ser implementada. Ajuda a gerar soluções mais técnicas para auxiliar no processo de venda.

#### Análise de Custos para o Negócio
- Realiza uma análise de custos para o negócio: Ajuda a quantificar gastos de implantação de software, incluindo licenças, integrações e migrações.

- Fornece previsibilidade em relação aos custos da solução total, após a implantação, complementando o que a área de vendas pode precificar.

#### Resumo do Arquiteto de Soluções
É um profissional técnico, que gosta de negócio, entende de tecnologia, comunica-se bem e consegue expressar em números e diagramas as necessidades da empresa.
