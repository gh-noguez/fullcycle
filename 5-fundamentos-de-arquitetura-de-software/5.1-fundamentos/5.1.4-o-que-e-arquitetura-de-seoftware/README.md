# O que é arquitetura de software.

- É uma disciplina da engenharia de software.

- Está diretamente ligada ao processo de desenvolvimento de software (o software development life cycle).

- É um trabalho mais "baixo nível" se comparado à arquitetura de solução.

- Pode parecer que o arquiteto de software só desenha, mas ele tem uma função prática e crucial.

- Importante: Existe uma interseção entre a arquitetura de software e a de solução, o que pode causar confusão. A diferença principal é o nível de granularidade.

#### Impacto na Estrutura Organizacional (Lei de Conway)
A arquitetura de software afeta diretamente a estrutura dos times de software em uma empresa.

- A forma como a arquitetura do sistema é definida pode determinar a divisão dos times.

- Lei de Conway: "As organizações que desenvolvem sistemas de software tendem a produzir sistemas que são cópias das estruturas de comunicação dessa empresa."

    - Exemplo: Se uma equipe é composta por um desenvolvedor Back-End, um Front-End e um DBA, a arquitetura do software provavelmente será um sistema Back-End, um Front-End e um banco de dados separados.

#### Definição e Objetivos
- Definição: A arquitetura de software é a relação entre os objetivos de negócio e as suas restrições, considerando os componentes a serem criados e suas responsabilidades, com o objetivo de evoluir o software.

- Ao arquitetar, o foco não está apenas no software como um todo, mas em como ele será dividido em componentes para atender aos objetivos de negócio, levando em conta restrições como financeiras, de equipe ou tecnológicas.

- Definição Formal (ISO): "A arquitetura de software é a organização fundamental de um sistema e seus componentes, suas relações, seu ambiente, bem como os princípios que guiam seu design e evolução."

- O ponto mais importante dessa definição é a ênfase na evolução do software. Um software deve ser pensado para o longo prazo, não apenas para o momento. A arquitetura de software garante que o sistema seja sustentável e possa ser evoluído.

#### Resumo dos Pontos Principais
- Disciplina da engenharia de software.

- Ligada ao processo de desenvolvimento.

- Afeta a estrutura e formação dos times (Lei de Conway).

- Envolve a estruturação de componentes.

- Foca na sustentabilidade e evolução do software.
